# IKPM — trzy wersje interfejsu (prototypy)

Klikalne prototypy programu do wycen i realizacji prac remontowych (praca inżynierska): Foldery, Kreator, Kosztorys.
Statyczny HTML z Bootstrap 5 i Alpine.js, dane przykładowe w `*/assets/kit.json`; zmiany zostają w przeglądarce
(`localStorage`). Strona: https://grywam7.github.io/ikpm-warianty/

Źródło prototypów jest poza tym repozytorium; aktualizacja — kopia trzech katalogów bez `README.md` i `screens.json`.
